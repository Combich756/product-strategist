# Роуминг-Старт · паспорт вымышленного пилота
Роуминг-Старт — вымышленный eSIM-пакет мобильных данных для поездок. Все показатели и процессы пилота ниже смоделированы.
В сценарии подключение возможно на совместимом разблокированном устройстве. Профиль можно установить заранее при наличии интернета, пакет начинает действовать при первом подключении к поддерживаемой сети в зоне покрытия.
Действующий экран после покупки содержит ссылку «Установить eSIM» и справку; проверка совместимости показывается до оплаты. В демонстрационном сценарии доступна одна продуктовая итерация за месяц, максимум 80 часов команды, без расширения покрытия.
В выгрузке за W41 и W42 единица — оплаченный совместимый заказ с известной датой прибытия, для которого прошли 48 часов после прибытия. `connected_48h` — заказы с первой сессией мобильных данных по eSIM в течение этих 48 часов. Срезы по платформе и неделе не пересекаются.
Поддержка в сценарии записала два возможных вопроса покупателей: «Установка сразу запустит пакет?» и «Как выбрать eSIM для интернета по прибытии?». Это сценарные примеры обращений без частот, не интервью.
Маржа заказа, сроки биллинга и стоимость обращений в материалах отсутствуют. Бесплатный Wi-Fi, роуминг домашнего оператора и туристические eSIM других поставщиков — альтернативы клиента.
