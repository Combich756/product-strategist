# OneDrive · открытая справка об истории версий
URL https://support.microsoft.com/en-us/onedrive/restore-a-previous-version-of-a-file-stored-in-onedrive
Проверено 2026-11-11. В OneDrive пользователь может открыть историю версий файла, выбрать предыдущую версию и восстановить её. Восстановленная версия становится текущей.
Это альтернатива для задачи возврата прежней версии отдельного файла. Границы полного восстановления резервной копии из этой справки не следуют.
