# Паспорт учебного пилота «ДоПечати»
Кейс вымышленный. В пилоте участвовали два формата онлайн-печати, плакат (poster) и буклет (booklet). Базовый путь — обычная загрузка PDF. Пилотная группа видела дополнительную необязательную кнопку проверки перед отправкой.
С 2 по 8 ноября 2026 года включительно первые подходящие заказы назначались случайно внутри каждого формата в группы standard и offer в равной пропорции. Для каждого заказа учтён один исход. Срез сделан 18 ноября 2026 года в 12:00 по Москве. Во всех строках прошли полные семь суток наблюдения после первой загрузки.
eligible — все назначенные заказы группы. first_pass — заказы, для которых производство приняло первый загруженный макет в течение семи суток без второй версии. used_check — заказы, в которых нажали кнопку. first_pass_among_users — первые принятия в этом подмножестве. Нажатие кнопки было добровольным.
Владелец рассматривает включение кнопки для всех заказов конкретного формата, если в группе offer не менее 75% всех назначенных заказов прошли с первого раза, а дополнительная работа поддержки не превысила 35 минут на 100 назначенных заказов этого формата. Обе границы включительные, оба условия должны выполняться для одного формата. Для формата, который сейчас не проходит, сохраняем стандартную загрузку.
В распоряжении команды одна двухнедельная итерация. Команда может включить кнопку для одного или обоих форматов и замерить результат. Только руководитель продукта утверждает запуск. Контрольный срез следующей когорты проводят после закрытия семидневного окна для её последнего заказа.
