# ДоПечати

Руководитель сервиса онлайн-печати решает, каким покупателям предложить проверку PDF перед отправкой макета в производство. В четырёх синтетических материалах есть данные по плакатам и буклетам. Владелец выбирает действие на следующие две недели. [Запрос владельца](request.md) · [Материалы](materials/)

Агент рекомендует предлагать проверку покупателям плакатов. В этой группе при предложении кнопки производство приняло с первого раза 80 заказов из 100. Дополнительная поддержка заняла 32 минуты на 100 заказов. Для буклетов значения составили 70 из 100 и 46 минут. Пороги пилота составляют соответственно не менее 75 первых принятий и не более 35 дополнительных минут. Владелец ещё не утверждал запуск. [Стратегия для владельца](strategy.md)

## Проверка результата

Из корня проекта пересчитайте доли и переменные затраты по двум исходным CSV.

```bash
python3 demo/dopechati/evidence/reference_values.py
```

Сохранённые значения позволяют сверить вывод. До прогона были зафиксированы восемь критериев. По каждому в оценке указаны наблюдение и материал для проверки. [Расчёты](evidence/recomputed.json) · [Критерии](evidence/pre-run-rubric.json) · [Оценка](evidence/score.json)

После прерывания первого сеанса агент продолжил с сохранённого исследования. Отдельный проверяющий изучил итоговую версию стратегии перед показом владельцу. Прогон выполнен в Codex на версии `716b902`. [Восстановление](evidence/recovery-story.json) · [Вердикт](evidence/review-1/verdict.json) · [Журнал CLI](evidence/cli.jsonl)

В журнале сохранены имена путей исходного запуска. Его запрос, материалы и черновики из `cases/dopechati/` в этой папке находятся в `request.md`, `materials/` и `drafts/`.
