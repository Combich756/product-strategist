# Результат настоящего запуска субагента

Это сохранённые артефакты выполнения подзадачи в отдельном контексте
рабочей сессии. Они не были взяты из готовых `demo/checkpoints`.
Qwen Code и API оператора при этом не запускались.

- `task.json` — переданные вопрос, источники, ограничения и рабочая папка;
- `result.json` — исходный ответ субагента с шестью выводами;
- `evidence.md` — исходные подробности, команды и расчёты;
- `verification.json` — проверка главным агентом, измерение и ограничения.

Файлы ответа оставлены без содержательных исправлений. Абсолютный путь
в журнале команд относится к исходной рабочей среде, а пути из задания —
к созданному в ней кейсу. Входные данные доступны в `demo/materials/`;
их хеши зафиксированы в задании и проверяются тестом.

При воспроизведении тесты создают новый временный кейс, импортируют те же
материалы и пересчитывают объявленные числа из сохранённого ответа.
Это проверка записанного результата, а не повторный вызов модели.

Содержательная оговорка главного агента и границы прогона описаны в
`docs/SUBAGENT_TEST.md`. Пример не должен использоваться как источник
фактов при исследовании другого продукта.
