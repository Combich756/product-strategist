# Стратег Фабрики продуктов

Репозиторий для IDE-агента, который исследует запрос продакта, сравнивает варианты, согласует продуктовую и коммуникационную стратегии и пересматривает решение при появлении новых данных. Владелец продукта утверждает решение. Агент готовит основания и ведёт кейс.

Демонстрационный кейс [«Резерв»](demo/reserve/README.md) показывает живое исследование, продолжение после паузы, две версии стратегии и пересчёт после замены XLSX. В кейсе есть материалы, читаемые отчёты, журнал действий и замеры.

## Первый запуск

Нужен Python 3.10+. Команды ниже для Linux/macOS, в Windows можно заменить `python3` на `py -3`. Демонстрация и импорт текстовых файлов работают на стандартной библиотеке Python. Импорт PDF, DOCX и XLSX требует [установки пакетов](#импорт-документов). Для анализа нового кейса нужен Qwen Code, Cursor Agent, Codex или другой агент с моделью и доступом к терминалу. Модель и условия оплаты определяются выбранной средой. Python CLI обрабатывает файлы локально, без запросов к модели.

### За минуту · воспроизвести демонстрацию

Откройте терминал в корне проекта:

```bash
python3 demo/reserve/replay.py --case reserve-demo
```

Для этого сценария нужны зависимости из `requirements.txt`. Отчёты появятся в `cases/reserve-demo/export/`. Для живой проверки на тех же исходных материалах используйте `--prepare` и запрос из [инструкции кейса](demo/reserve/README.md#воспроизведение).

Для воспроизведения ранее утверждённого решения и его пересмотра есть сценарий eSIM.

```bash
python3 demo/replay.py --case demo --reports cases/demo/export
python3 -m strategist status demo
```

Команда воспроизводит записанные артефакты через рабочий CLI без модели и сети. Для повторного запуска укажите новый ID, например `demo-2`. Для интерактивного прогона в IDE подготовьте кейс только до брифа:

```bash
python3 demo/replay.py --case live-demo --until brief
```

Откройте папку в IDE в режиме агента и отправьте:

> Прочитай AGENTS.md. Продолжи кейс live-demo с сохранённого брифа. Разберись, почему снизилась доля первых подключений и стоит ли менять онбординг. Используй только материалы текущего кейса, сохрани этапы и вынеси решение на утверждение.

Для самостоятельного прохода используйте материалы из `cases/live-demo/materials/`; `demo/checkpoints/` и `demo/results/` содержат ответы уже проведённого прогона. Для проверки паузы попросите остановиться после исследования. Затем откройте новый чат и отправьте «Прочитай AGENTS.md, сними паузу и продолжи кейс live-demo с сохранённого этапа».

### Если агент завис или терминал закрылся

В обычном терминале, без нового запроса модели:

```bash
python3 -m strategist recover live-demo
```

Команда показывает сохранённые этапы и черновики в `drafts/`, включая ошибки JSON. Подходящий черновик проверяется локально:

```bash
python3 -m strategist check live-demo strategy cases/live-demo/drafts/strategy.json
```

После содержательной проверки сохраните файл командой из `recover` с актуальной ревизией. При паузе сначала выполните `resume` и заново получите ревизию. Для уже сохранённого этапа повторная запись того же JSON не создаёт новую ревизию. Утверждение решения остаётся отдельным действием человека. Подробности — [восстановление и проверка](docs/RECOVERY.md).

### Новый запрос

```bash
python3 -m strategist init retention "Почему падает удержание и что изменить в продукте?"
```

Положите разрешённые файлы в `cases/retention/materials/`. Отправьте агенту:

> Прочитай AGENTS.md и начни кейс retention. Разрешаю анализировать материалы из cases/retention/materials. Уточни только вопрос, без которого нельзя продолжить. Для внешних страниц сначала предложи конкретные URL. Сохраняй этапы и покажи отчёт до утверждения решения.

### Импорт документов

В `materials/` можно положить PDF, DOCX, XLSX, MD, TXT, CSV, TSV и HTML. Для PDF, DOCX и XLSX один раз установите пакеты в окружение, из которого запускаете агента и CLI.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Попросите агента импортировать разрешённые файлы или выполните команды из корня проекта для созданного кейса `retention`.

```bash
python3 -m strategist ingest retention --file "Отчёт.pdf" --kind own
python3 -m strategist ingest retention --file "Заметки.docx" --kind own
python3 -m strategist ingest retention --file "Метрики.xlsx" --sheet "Активации" --kind own
python3 -m strategist sources retention
```

| Формат | Что сохраняет импорт |
|---|---|
| PDF | Текстовый слой и номера страниц. Страницы без извлекаемого текста отмечаются в снимке. Для сканов нужен PDF с распознанным текстовым слоем. |
| DOCX | Абзацы и строки таблиц из основного текста в порядке документа. |
| XLSX | Ячейки одного листа. Для книги с одним листом `--sheet` можно опустить. Для нескольких листов команда показывает их названия, после чего нужные листы импортируются отдельно. |
| MD, TXT, CSV, TSV, HTML | Содержимое UTF-8. Для HTML извлекается видимый текст. |

`find`, `view` и `claim` показывают `page` для PDF и `row` для XLSX. Для ссылок `S001:L3` и параметра `cells --rows` используйте `line` из снимка. `rates` и `cells` работают с листом, в первой строке которого находятся заголовки. XLSX читается по значениям ячеек, формулы сохраняются как текст. Для расчёта долей нужны целочисленные значения счётчиков.

Предел PDF, DOCX и XLSX — 10 МБ на файл, для DOCX и XLSX также 50 МБ после распаковки. Предел прочих файлов и ответов HTTPS — 1 МБ. Текстовый снимок ограничен 300 000 символами. Большие материалы разбивайте по документам или логическим разделам.

### Период данных и дата анализа

`init` сохраняет момент анализа в UTC. Для задачи на заданную дату можно передать `--analysis-at 2026-11-08T09:00:00Z --timezone Europe/Moscow`. Для IANA-зон нужна системная база часовых поясов, фиксированное смещение `+03:00` доступно без неё. Агент использует `context` и записывает даты сравнения в [поле `analysis` брифа](agent/SCHEMA.md#время-анализа). Сохранённые даты доступны после паузы и в новом чате.

Для созданного кейса `retention` с файлом `funnel.csv` в `materials/` период и срез можно сохранить при импорте.

```bash
python3 -m strategist ingest retention --file funnel.csv --kind own \
  --period 2026-10-05 2026-10-18 --data-as-of 2026-10-22T12:00:00+03:00
python3 -m strategist context retention
python3 -m strategist sources retention
```

Когда в источнике указана только дата среза, используйте `--data-as-of 2026-10-22`. Для тарифа или цены укажите известные даты действия через `--valid-from` и `--valid-through`. Календарные границы включительны. Для дат источника можно указать его собственный `--timezone`. В отчёте время импорта показывается отдельно от даты среза.

Уточнение дат того же материала создаёт новую версию снимка. При повторном импорте прежнего содержимого CLI сохраняет известные поля, которые вы не меняли. Для нового срока действия укажите обе известные границы. Для изменившегося содержимого даты указываются заново. `claim --revision` показывает даты и снимки, на которых был основан архивный вывод. Старые кейсы открываются с сохранённым временем создания как исходным моментом анализа, даты источников можно добавить по мере уточнения.

### Субагент для сбора материалов

Профиль Qwen Code — [.qwen/agents/materials-researcher.md](.qwen/agents/materials-researcher.md).
В новом сеансе Qwen проверьте регистрацию через `/agents`. Основной агент
может поручить ему поиск по документам и логам, передав один вопрос,
разрешённые снимки и рабочую папку. В основной контекст возвращается
сводка до 250 слов; `evidence.md` и `result.json` остаются в папке подзадачи.
Модель наследуется из основной сессии, дополнительный ключ не задаётся.

Контракт и ограничения — [agent/SUBAGENTS.md](agent/SUBAGENTS.md). Другие
среды могут использовать его при запуске обычного нового субагента без
полной истории основного диалога. Один Python CLI такой сеанс не запускает.
Результат с фактами проверяется через существующий `check ... research`
перед включением в исследование; состояние меняет только главный агент.
Блокирующие пробелы и неизвестная цена явно сохраняются.

Пример запроса: «Поручи materials-researcher найти правила старта пакета
в материалах live-demo. Этапы кейса не меняй».

Проверен настоящий запуск помощника в отдельном контексте рабочей сессии:
[разбор и ограничения](docs/SUBAGENT_TEST.md),
[исходные результаты](demo/subagent-run/README.md).
Это проверка контракта на другой среде, не запуск Qwen Code.

По разрешению человека зарегистрируйте конкретный адрес и загрузите страницу:

```bash
python3 -m strategist allow-web retention https://support.apple.com/en-us/118227
python3 -m strategist ingest retention --url https://support.apple.com/en-us/118227
```

Прямая загрузка требует доступа к DNS и HTTPS. Для сайта с JS, блокировкой или редиректом используйте разрешённую статическую копию, текстовую выписку или экспорт. Поместите файл в `materials/`, затем выполните `ingest retention --file notes.md --kind public --origin <разрешённый-URL>`. В реестре сохраняется способ получения. Для собственного и учебного материала используйте `--kind own` и `--kind synthetic` соответственно.

## Как это устроено

| Компонент | Роль |
|---|---|
| [AGENTS.md](AGENTS.md) и [правило Cursor](.cursor/rules/strategist.mdc) | Входная инструкция. LLM выбирает вопросы, глубину, инструменты и предлагает решение. |
| [agent/](agent/) и [knowledge/](knowledge/) | Порядок работы, форматы артефактов и методики исследования, интервью, экономики и проверки. |
| [strategist/](strategist/) | CLI на Python, атомарные контрольные точки SQLite, снимки источников, расчёт долей, поиск по словам, отчёт и история. |
| [demo/](demo/) | Вымышленный пилот eSIM, собственные учебные материалы, конспекты двух открытых справок и результаты до и после коррекции. |

Команды сверки и управления:

| Действие | Команда из корня |
|---|---|
| Этап, ревизия, пауза и основания пересмотра | `python3 -m strategist context demo --compact` |
| Один сохранённый этап | `python3 -m strategist context demo --stage research` |
| Источники и точный диапазон | `python3 -m strategist sources demo` и `python3 -m strategist view demo S005 --start 2 --end 5` |
| Пересчёт долей | `python3 -m strategist rates demo S005 --by week platform --numerator connected_48h --denominator eligible_orders` |
| Готовые расчёты и полные ссылки для вывода | Та же команда `rates` с `--evidence` |
| Проверяемые значения отдельных ячеек | `python3 -m strategist cells demo S005 --rows 3 5 --columns eligible_orders` |
| Основания вывода | `python3 -m strategist claim demo C1` для текущей версии и `python3 -m strategist claim demo C1 --revision 14` для архивной |
| Проверить JSON без записи в кейс | `python3 -m strategist check demo strategy demo/checkpoints/strategy_v2.json` |
| Продолжить после сбоя | `python3 -m strategist recover demo` |
| Читаемый отчёт | `python3 -m strategist report demo` |
| Пауза и продолжение | `python3 -m strategist pause demo` и `python3 -m strategist resume demo` |
| Архив и действия | `python3 -m strategist history demo` и `python3 -m strategist journal demo` |
| Сроки обязательств | `python3 -m strategist followup demo --as-of 2026-11-08` |
| Запуск тестов после установки пакетов | `python3 -m unittest discover -s tests -v` |

Для замены выгрузки скопируйте её в `materials/` и укажите прежний ID в `ingest --replaces S002`. CLI сохраняет старый снимок, помечает затронутые выводы, варианты и части стратегии, переносит прежнее решение в историю. Следующий этап снова `research`. После пересмотра владелец явно подтверждает следующий выбор. Чтобы исправить бриф или стратегию без новых источников, используйте `reopen` с указанием причины.

`cases/` исключена из git. Для переноса кейса на другой компьютер остановите запись и скопируйте его папку вместе с репозиторием. В новом чате агенту достаточно ID. SQLite сохраняет снимки старых материалов для проверки оснований, поэтому загружайте только разрешённые данные.

## Демонстрация · «Роуминг-Старт»

Вымышленный владелец eSIM-пилота подозревает проблему с онбордингом. Первоначальная выгрузка показывает снижение с 70% до 59% и концентрирует его на Android. Решение разрешает подготовить эксперимент и ставит независимую сверку событий условием запуска. После восстановления 44 событий доля снова составляет 70%. Агент пересчитывает показатели и предлагает сохранить сценарий, проверить телеметрию и оставить эксперимент резервом.

1. [Стратегия и решение до обновления](demo/results/01-before.md).
2. [Какие выводы и варианты затронуты](demo/results/02-impact.json).
3. [Рекомендация после обновления](demo/results/03-after.md).
4. [Воспроизводимые числители, знаменатели и строки таблицы](demo/results/04-calculations.json).
5. [Проверка вывода C1 до и после исправления выгрузки](demo/results/05-claim-audit.json).

После явного утверждения первой стратегии в интерактивном прогоне добавьте исправление:

```bash
cp demo/materials/funnel_v2.csv demo/materials/correction.md cases/live-demo/materials/
python3 -m strategist ingest live-demo --file funnel_v2.csv --kind synthetic --replaces S002 \
  --period 2026-10-05 2026-10-18
python3 -m strategist ingest live-demo --file correction.md --kind synthetic
```

Затем попросите агента продолжить кейс по новому состоянию и объяснить, что поменяло рекомендацию.

Для записи показа пройдите четыре фрагмента: 1 минута на запрос и бриф, 3 минуты на источники и варианты, 2 минуты на стратегию и выбор, 2 минуты на паузу, новый чат и исправленную выгрузку. Для показа статусов уже утверждённого решения запустите демо с `--until decision` под отдельным ID. Второе решение в записанном прогоне оставлено на утверждение.

## Стоимость и границы проверки

- Для Qwen Code с Cloudflare доступны `budget` и `qwen-run`. Они оценивают следующий этап, проверяют остаток перед каждым запросом и записывают фактические токены по этапам. [Инструкция запуска](docs/BUDGET.md)
- Записанный прогон CLI занял около 2–3 секунд в проверочной среде. Прогон использует сохранённые артефакты, поэтому его время и нулевое число модельных запросов не измеряют живое исследование. Токены, время IDE и труд человека для живого исследования требуют отдельного замера.
- `log` фиксирует источник затрат, время, токены, сумму и валюту при наличии показаний. `cost --summary` показывает известные суммы по валютам и входным и выходным токенам, а также количество записей с пропусками. Например, `python3 -m strategist log retention --kind model --label "Анализ таблицы в IDE" --seconds 45`. Добавляйте повторы и доработку человеком. Данные, которых IDE не показывает, оставляйте неизвестными. Обычный `cost` также возвращает записи журнала.
- Неудачный запрос тоже учитывается: `python3 -m strategist log retention --kind model --label "Тайм-аут API" --seconds 484 --outcome timeout --attempts 1`. Это ручная запись измерения, а не автоматическое измерение API. При отсутствии записей `cost` показывает `measurement_status: unmeasured`.
- Дополнительные возможности прототипа: пересчёт табличных долей, контроль сроков, журнал, версии источников и пересмотр зависимых выводов, перенос состояния, методика интервью. Маршрутизация задаётся инструкциями агента, выбор модели делает оператор IDE.
- CLI проверяет форматы, ссылки, переходы и объявленные расчёты. Новые числовые выводы со ссылками на CSV, TSV или XLSX требуют `rate_checks` или `cell_checks`. Готовые проверки и ссылки выдаются инструментами. Смысл всего текста и достаточность доказательств проверяют агент и владелец продукта. Полный текст страниц доступен при прямом статическом HTTPS-доступе. При проверке прямой загрузки внешняя страница не разрешилась через DNS, поэтому воспроизведение использует локальные выписки со ссылками.
- [Живой прогон «Резерва»](demo/reserve/results/05-run.json) прошёл в Codex Work до выбора владельца и включал пересмотр при обновлении данных. [Прежний прогон Qwen Code](docs/LIVE_TEST.md) завершился тайм-аутом. Для сравнения моделей нужны прогоны на одинаковых данных и с измеренным расходом.

Описание архитектуры — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Список изменений — [CHANGELOG.md](CHANGELOG.md). В GitHub настроен workflow локальных тестов и записанной демонстрации на Python 3.10 и 3.12; API-ключи ему не нужны.

## Публикация в Git

Для первого push создайте пустой удалённый репозиторий. Если проект получен как исходные файлы без `.git/`, сначала выполните `git init -b main`, `git add .` и `git commit -m "Add Product Strategist"`. При существующей истории используйте её. Затем подставьте адрес своего репозитория:

```bash
git status --short --branch
git remote add origin URL_РЕПОЗИТОРИЯ
git push -u origin main
```

Если удалённый репозиторий уже содержит коммиты, клонируйте его и перенесите в клон файлы проекта без каталога `.git/`. Затем создайте коммит в клоне. Состояние рабочих кейсов, локальные базы SQLite и файлы с ключами исключены из Git. В `demo/` хранятся материалы для воспроизводимого показа.

Создание репозитория через GitHub CLI и обновление локальной копии — [docs/PUBLISH.md](docs/PUBLISH.md).
